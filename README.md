# Customer-Shopping-Behavior-Analysis
An end-to-end data analytics project analyzing customer shopping behavior using Python, MySQL, SQL, and Power BI to uncover customer segments, purchasing patterns, revenue trends, and business insights.
# 📊 Data Analytics Project

## 📌 Overview

This project demonstrates an end-to-end **Data Analytics workflow**, including data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis using **MySQL**, dashboard creation using **Power BI**, report generation, and presentation development using **Gamma AI**.

The goal of this project is to transform raw data into meaningful insights through data analysis, visualization, and business intelligence techniques.
